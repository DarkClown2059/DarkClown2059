# About Me

I'm a **Computer Science undergraduate** learning how to build real software from the ground up.

Currently focused on:

* Web development
* Backend systems & APIs
* JavaScript and programming fundamentals
* Databases and data-driven applications
* Building projects instead of just following tutorials

I'm particularly interested in understanding **how things work underneath the interface** — from browser behavior and HTTP to APIs, databases, authentication, and backend architecture.
